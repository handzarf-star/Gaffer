# Brand: Gaffer

Working name **Gaffer**. It is a one-line change in `src/shared/brand.ts` (plus `index.html`, `public/manifest.webmanifest`).

## Checks to run before you promote it (not run, so nothing here is claimed as available)

| check | where | result |
| --- | --- | --- |
| US trademark | tmsearch.uspto.gov, classes 9 and 41 | to run |
| EU / UK trademark | EUIPO eSearch, UK IPO | to run |
| domain | your registrar | to run |
| App stores | search "Gaffer" | to run (the word is common football slang, so expect other apps) |
| the web | search "gaffer football game" | to run |

These are screening checks, not legal clearance.

## What was rebranded

- Name, tagline, palette (emerald, royal blue, ink; contrast-checked), logo (own SVG), type (Bricolage Grotesque + Inter, both open fonts), copy (all written fresh).
- Tactic names and headings that echoed the original were renamed.
- `npm run check:brand` fails if the original's name, domain or signature colours appear anywhere in the shipped project.

## Logo brief (if you want a real one)

A mark that reads at 16px and 1024px: a centre circle and halfway line with a gold ball dot, on a deep-green tile. Deliver SVG plus a 1024px icon without transparency. The included mark is a placeholder drawn for this project.
